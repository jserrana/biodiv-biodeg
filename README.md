Codes for: Metagenomes and metagenome-assembled genomes from European river sediments linked to experimentally determined biodegradation rates
--- 
This repository contains the supplementary data and analysis scripts associated with the Scientific Data Data Descriptor:

Serrana JM, Tian R, Posselt M. Metagenomes and metagenome-assembled genomes from European river sediments linked to experimentally determined biodegradation rates.

### Overview

This dataset combines shotgun metagenomic sequencing data from 19 European river sediment samples with environmental metadata and experimentally determined biodegradation rate constants previously reported by Tian et al. (2024). The resource includes:

Metagenome-assembled genomes (MAGs)
Taxonomic classifications generated using GTDB-Tk
Phylogenomic reconstruction
MAG abundance estimates
Environmental metadata
Biodegradation measurements
Analysis scripts used for data processing and visualization

### Repository contents:

MS-EU-Data-Decriptor_R-Codes.Rmd ### R Markdown file containing the code used to: Process metadata; Summarize MAG characteristics; Generate   manuscript figures; Produce statistical summaries; Construct data visualizations used in the Data Descriptor

MS-EU-Data-Decriptor_Supplementary-Tables.xlsx ### Supplementary tables accompanying the Data Descriptor. Include: Sample metadata; Environmental measurements; Sequencing statistics; MAG quality metrics; GTDB-Tk classifications; MAG abundance estimates; Additional information required for dataset reuse

gtdbtk.bac120.user_msa.tree ### Phylogenomic tree reconstructed from the GTDB bac120 marker-gene alignment generated by GTDB-Tk. 

### External data repositories:

Tian R, Posselt M, Fenner K & McLachlan MS (2024). Variability of biodegradation rates of commercial chemicals in rivers in different regions of Europe. Environmental Science & Technology 58, 20201-20210.
